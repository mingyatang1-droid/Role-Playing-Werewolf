## 1. 已完成功能

### 1.1 工程与基础服务

- 客户端与服务端独立工程。
- 服务端 HTTP 健康检查 `GET /v1/health`。
- WebSocket 占位连接 `WS /v1/ws`、首帧握手和心跳响应。
- Vitest 单元与接口测试。
- SQLite 文件数据库和 PostgreSQL 适配器。
- Docker Compose PostgreSQL 本地配置。

### 1.2 微信登录

- 客户端调用 `wx.login()` 获取 code。
- 服务端支持 Mock 登录和真实微信 `jscode2session` 登录。
- 微信 `openid` 仅保存在服务端，不返回客户端。
- 内部用户 UUID 和可展示的 `public_id`。
- 不获取、不承诺保存用户微信号。
- 首次登录设置昵称。
- Opaque 会话 Token；数据库只保存 Token 的 SHA-256 哈希。
- 客户端启动时自动恢复登录状态。

接口：

```text
POST  /v1/auth/wechat
GET   /v1/me
PATCH /v1/me/profile
```

### 1.3 客户端首页

- 暗夜悬疑风格的登录页和首页。
- 微信原生胶囊安全区适配。
- 用户昵称和 `public_id` 展示。
- 单人开局入口。
- 好友房和最近对局占位。
- 点击单人开局进入房间配置。

### 1.4 单人房间配置

- 支持 6～12 人，默认 9 人。
- 切换人数时自动套用推荐角色模板。
- 可调整狼人、村民、预言家、女巫、猎人数量。
- 客户端和服务端双重校验。
- 创建成功展示房间编号、玩家人数和角色摘要。
- 房间及席位保存到数据库。

接口：

```text
POST /v1/rooms
GET  /v1/rooms/:room_id
```

数据库表：

```text
users
user_sessions
rooms
room_seats
```
